# EcoWorkout · CV Digital - Adriana Castañeda

CV digital profesional de Adriana Castañeda García, entrenadora personal especializada en cultura física y deporte.

## Características
- **Diseño responsivo** con enfoque en UX/UI.
- **Header fijo** con menú hamburguesa para móviles.
- **Línea de tiempo híbrida**: horizontal en escritorio, vertical en móviles.
- **Carrusel de competencias** con imágenes y auto-reproducción.
- **Precios dinámicos** desde Google Sheets (CSV público).
- **Footer** con redes sociales y crédito de diseño.

## Tecnologías
- HTML5, CSS3, JavaScript (Vanilla)
- FontAwesome para iconos
- Google Fonts (Inter)
- Google Sheets API (CSV)

## Despliegue
Este sitio está diseñado para GitHub Pages. Sube todos los archivos y activa Pages desde la rama `main`.

## Configuración de Google Sheets
- La hoja de precios debe estar publicada como página web.
- La URL CSV está configurada en `js/script.js`.
